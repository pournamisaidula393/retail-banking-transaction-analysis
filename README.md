# Retail Banking Transaction Analysis Using MySQL

## Project Overview

This project analyzes retail banking data using MySQL to generate business insights from customer, account, transaction, loan, and card information.

## Tools Used

- MySQL
- MySQL Workbench

## Tables Used

- Customers
- Branches
- Accounts
- Transactions
- Loans
- Loan Payments
- Cards

## SQL Concepts Used

- JOINs
- Aggregate Functions
- Subqueries
- GROUP BY and HAVING

## Project Objectives

- Analyze customer information and segmentation.
- Examine account balances and transaction patterns.
- Analyze loan payments and performance.
- Explore card usage and banking products.

- SQL_PROJECT.sql — SQL queries and analysis
